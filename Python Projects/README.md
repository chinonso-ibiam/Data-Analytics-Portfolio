# Featured Analytics Projects

## Telecom Customer Churn Analysis

Tools Used:
- SQL
- Python
- Excel
- Power BI

Project Workflow:

Business Understanding
↓
Data Cleaning
↓
SQL Analysis
↓
Python EDA
↓
Power BI Dashboard
↓
Business Recommendations

Key Findings:

• Churn Rate: 26.54%

• Month-to-Month customers exhibited the highest churn.

• Customers in their first 12 months were most likely to churn.

• Higher monthly charges were associated with increased churn.

• Contract type emerged as the strongest churn predictor.
