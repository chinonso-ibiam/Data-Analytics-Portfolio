## Project Overview

This project is an interactive Excel dashboard developed using the Superstore dataset to analyze sales performance, customer behavior, and regional trends from 2015–2018.

---

## Business Questions

- Which year generated the highest sales?
- How many distinct orders were placed?
- How many unique customers made purchases?
- Which category generated the most revenue?
- Which region performed best?
- Who are the top customers?

---

## KPIs

- Total Sales
- Total Orders (Distinct Order IDs)
- Total Customers (Distinct Customers)
- Average Order Value (AOV)
- Year-over-Year Growth

---

## Dashboard Features

### Interactive Filters

- Year
- Category
- Segment
- Region
- Ship Mode

### Visualizations

- Monthly Sales Trend
- Sales by Category
- Sales by Segment
- Sales by Region
- Ship Mode Distribution
- Top 10 States
- Top 10 Customers

---

## Key Insights

### Sales Growth

Sales increased significantly from 2017 to 2018.

### Customer Behavior

Order volumes increased while Average Order Value slightly declined.

### Product Performance

Technology was the top-performing category.

### Regional Performance

The West region generated the highest sales.
