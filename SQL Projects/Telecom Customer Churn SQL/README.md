
# Telecom Customer Churn SQL Analysis

## Overview

SQL analysis performed on the Telecom Customer Churn dataset to identify key churn trends and customer behavior patterns.

## Analysis Conducted

- Total Customers
- Churned Customers
- Retention Rate
- Churn Rate
- Churn by Gender
- Churn by Contract Type
- Churn by Internet Service
- Churn by Tenure Group
- Revenue Analysis

## Key Findings

- Month-to-Month customers exhibited the highest churn.
- Customers with lower tenure churned more frequently.
- Fiber Optic subscribers accounted for a significant proportion of churn.
- Higher monthly charges were associated with increased churn.
